# SQL

## DDL
- CREATE：创建数据库、表、索引等对象
- ALTER：修改数据库、表、索引等对象
- DROP：删除数据库、表、索引等对象
- TRUNCATE：清空表中的数据，但保留表结构
- GRANT：授予用户权限

## DML
- SELECT：查询数据（部分资料单独划为 DQL，工程中统一归 DML）
- INSERT：新增数据
- UPDATE：修改已有数据
- DELETE：删除数据

```sql
--SELECT 用法

-- 查询全部学院
SELECT * FROM college;
-- 只查学院ID、名称
SELECT college_id,college_name FROM college;
-- 查询电物学院(x1)下所有专业
SELECT major_id,major_name FROM major WHERE college_id='x1';
-- 联表：查询学生姓名+所属专业+学院
SELECT s.stu_id,s.stu_name,m.major_name,c.college_name
FROM student s
JOIN major m ON s.major_id=m.major_id
JOIN college c ON m.college_id=c.college_id;

GROUP BY
    id
LIMIT
    0,10
WHERE
    id>10 AND id<>10 AND id!=10
HAVING
    id>10


-- 筛选
select * from staff 
where level in('L1','L2','L3');

select * from staff 
where level not in('L1','L2','L3');

-- 排序
select * from staff order by salary;

select * from staff order by level,salary desc limit 3;

-- 合并重复项
select distinct gender from staff;

```


## 多表查询（表连接）
无效：笛卡尔乘积，行n*m,列 n+m
    select * from staff,dept;
- 内连接（等值连接）
-- s 代表staff，d代表dept，别名简化书写
```sql
SELECT s.name, d.name dept_name, d.city,salary,bonus
FROM staff s
INNER JOIN dept d
ON s.dept_id = d.id;
```
- 外连接
    - 左连接:保留左表 staff 全部员工，没有匹配部门的员工，部门字段填充NULL（marry 的 dept_id 是 null 也会显示出来）
    - 右连接：保留右表dept全部部门，没有员工的部门，员工字段填NULL
    - 全连接
    ```sql
    -- 左连接
    SELECT s.name, d.name dept_name, d.city
    FROM staff s LEFT JOIN dept d ON s.dept_id = d.id
    UNION
    -- 右连接
    SELECT s.name, d.name dept_name, d.city
    FROM staff s RIGHT JOIN dept d ON s.dept_id = d.id;
    ```

#### 聚合函数
- count()：统计行数
- sum()：求和
- avg()：求平均值
- max()：求最大值
- min()：求最小值
```sql
select max(salary),min(salary),avg(salary),count(salary) from staff;



```
分组
```sql
select dept_id,count(*) from staff group by dept_id;
select dept_id,count(*) from staff group by dept_id having count(*)>1;
```


```sql
-- 各部门的平均工资
SELECT d.name, count(s.id), avg(s.salary)
FROM staff s
JOIN dept d
ON s.dept_id = d.id
GROUP BY d.name
ORDER BY d.name DESC;
```


### 模糊查询

SELECT 字段 FROM 表 WHERE 字段 LIKE '匹配模板';

匹配模板
'_a%';      a前有一个字母的字段
'%a%';      含有a的字段
'a%'        a开头的字段
'%a'        a结尾的字段
'%t_'       倒数第二个字符为t
...

### 子查询

把一条select查询结果，当做另一条 SQL 的值 / 集合 / 表使用。
```sql
select name,salary from staff 
where salary > (select salary from staff where name = 'tom');
```
