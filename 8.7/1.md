## 视图

- 定义：视图是虚拟表，数据库只保存视图的SELECT查询定义，不存储真实数据，数据仍然来自底层的基表（原始表）。
查询视图的时候，动态执行定义的 SQL，从基表拿结果。

- 基础语法
```sql
-- 创建视图 dept，staff
-- CREATE VIEW 视图名 AS
-- SELECT 查询语句;

CREATE VIEW v_staff_dept AS
SELECT s.id, s.name, s.salary, d.name
FROM staff s JOIN dept.d ON s.dept_id = d.id;

```

- 视图更改
1.可更新视图（单表，无 join、无 group by）
UPDATE 视图 → 基表数据发生真实变化
2.只读视图（多表 JOIN、GROUP BY、聚合、DISTINCT）
UPDATE 视图 → 直接报错，根本不能执行，不会改动基表。
3.ALTER VIEW / CREATE OR REPLACE VIEW 修改视图定义
只修改查询语句，不会修改基表里的任何一行数据。

## MySQL c API

结构体	说明
- MYSQL:数据库连接句柄，保存连接状态、错误信息
- MYSQL_RES:查询结果集，保存返回的所有行数据
- MYSQL_ROW:一行数据，char * 数组，row[0]第一列、row[1]第二列，全部字符串
- MYSQL_FIELD:字段元信息（列名、类型）


mysql_library_init() 初始化客户端库（可选）
mysql_init() 创建 MYSQL 连接句柄
mysql_real_connect() 连接数据库服务器
mysql_query() / mysql_real_query() 执行 SQL
增删改：不需要结果集；用mysql_affected_rows()获取影响行数
查询 SELECT：mysql_store_result()拿到结果集，循环读取行
查询完成：mysql_free_result()释放结果集内存
mysql_close()关闭数据库连接
mysql_library_end()释放客户端库（可选）


## 预处理语句 - 预防 SQL

MYSQL_STMT *stmt：预处理语句句柄（代替普通 mysql_query）
MYSQL_BIND bind[]：绑定参数结构体数组，描述每一个?占位符的数据类型、缓冲区地址、长度

优点：
1.语句在数据库引擎中提前编译好，每次调用直接执行
2.避免了SQL注入

    char *sql ="select id,name,dept from dept where if = ? "
    char *sql ="insert into dept(name,dept)values(?,?) ";
