# 数据库 - SQL

## DDL 数据定义语言


- 基本操作
- CREATE：创建数据库、表、索引等对象
- ALTER：修改数据库、表、索引等对象
- DROP：删除数据库、表、索引等对象
- TRUNCATE：清空表中的数据，但保留表结构
- GRANT：授予用户权限

- 示例
```sql
    create database udb;
    use udb;
    show tables;

    create table t1
    (
        id int auto_increment primary key,
        c2 char(4),
        c3 decimal(5,2),
    );

    ALTER TABLE t1 ADD c4 varchar(20);
    alter table t1 change c2 tittle varchan(20);
    alter table t1 drop column c3;
    alter table `t1 ` change `c4` `order` varchar();

    insert into t1(c2) values(football);


    -- 截断表：drop，create
    -- 保留表结构，删除表里数据，释放了空间，重置自动增长的序列
    truncate table t1;

    -- 删除表：表结构，数据，空间
    drop table t1;

    -- 删除数据
    delete from t1 where xxxx;
    delete from t1;

    -- GRANT
    create user 'abc'@'%' IDENTIFIED BY '123456';
    grant all on udb.* TO 'abc'@'%';
    grant all on mall.* TO 'abc'@'%';
    exit
    -- 
    mysql -u abc -p
```
