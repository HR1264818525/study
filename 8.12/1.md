## 继承
- 基类（父类）：被继承的类，拥有通用的属性和方法；
- 派生类（子类）：继承父类，自动复用父类成员，还能新增自己的成员、重写父类函数。
```
    class 子类名 : 继承权限 父类名
    {
        // 子类自己新增的成员变量、成员函数
    };
```
### 传参
```
    子类构造函数(参数) : 父类名(传给父类的参数)
    {

    }
```
- 重要坑：父类析构建议加 virtual
    - 如果用父类指针指向子类对象，delete 时只会调用父类析构，造成子类内存泄漏。

### 子类同名隐藏
子类定义了和父类函数名完全一样的普通成员函数（非虚函数），那么子类对象会直接屏蔽掉父类同名函数。
```cpp
class Base
{
public:
    void func()
    {
        cout << "父类func" << endl;
    }
};

class Son : public Base
{
public:
    // 同名隐藏，不是重写
    void func()
    {
        cout << "子类func" << endl;
    }
};

int main()
{
    Son s;
    s.func();       // 调用子类自己的
    s.Base::func(); // 强制调用父类版本
    return 0;
}

```
### 单继承与多继承
- 多继承
    - 语法：逗号分隔多个父类 + 各自继承方式

- 多继承最大隐患：菱形继承（钻石继承）
```
        A
      /   \
     B     C
      \   /
        D
```
D 同时继承 B 和 C，而 B、C 又都继承 A，导致 D 里面存在两份 A 的成员，数据冗余、二义性报错。

解决方案：虚继承 virtual

```cpp
class B : virtual public A
{
};
class C : virtual public A
{
};

```
虚继承会让公共父类 A 只保留一份副本，消除冗余。
开发原则：尽量少用多继承，能用组合替代就不用多继承。

## 多态

```c++
#include <iostream>
using namespace std;

// 基类：几何图形
class Geometry
{
public:
    // 虚函数：定义统一接口
    virtual void draw()
    {
        cout << "绘制通用几何图形" << endl;
    }

    // 重要：基类析构必须加virtual，防止内存泄漏
    virtual ~Geometry()
    {
        cout << "基类Geometry析构" << endl;
    }
};

// 子类1：线段
class Line : public Geometry
{
public:
    void draw() override
    {
        cout << "绘制一条直线段" << endl;
    }
    ~Line() override
    {
        cout << "Line析构" << endl;
    }
};

// 子类2：圆形
class Circle : public Geometry
{
public:
    void draw() override
    {
        cout << "绘制一个圆形" << endl;
    }
    ~Circle() override
    {
        cout << "Circle析构" << endl;
    }
};

int main()
{
    // 基类指针指向不同子类对象，同一个draw()产生不同行为——多态
    Geometry *p1 = new Line();
    Geometry *p2 = new Circle();

    p1->draw(); // 运行时识别是Line，调用Line::draw
    p2->draw(); // 运行时识别是Circle，调用Circle::draw

    delete p1;
    delete p2;
    return 0;
}

Circle析构

```
