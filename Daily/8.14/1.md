# C++ - STL

## 标准模板库
1. **容器 Container**：存放数据的结构（最常用）
2. **算法 Algorithm**：操作容器的函数（排序、查找、遍历等）
3. **迭代器 Iterator**：容器的 “指针”，连接容器和算法
4. **函数对象 Functor**：重载`()`的类，充当自定义规则
5. **适配器 Adapter**：改造现有容器 / 接口（stack、queue）
6. **空间配置器 Allocator**：底层内存分配（几乎不用手动写）


## 容器

数据结构的具体实现

- 序列式容器
    1. `vector` 动态数组（最常用）
    2. `deque` 双端队列
    3. `list` 双向循环链表
    4. `forward_list` 单向链表（C++11）
    5. `array` 固定大小静态数组（C++11）
    6. `string` 字符专用 vector（也算序列容器）
- 关联式容器
    1. `set` 集合
    2. `multiset` 可重复集合
    3. `map` 键值对映射
    4. `multimap` key 可重复映射
- 无序容器 ->哈希表
    1. `unordered_set`
    2. `unordered_multiset`
    3. `unordered_map`
    4. `unordered_multimap`
- 容器适配器
    1. `stack` 栈（后进先出 LIFO）
    2. `queue` 普通队列（先进先出 FIFO）
    3. `priority_queue` 优先队列（堆结构，优先级最高先出）
