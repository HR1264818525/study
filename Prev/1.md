# c++项目开发的准备工作

## 疑难杂症
- Boost
    C++ 老牌第三方库，提供大量标准库没有的工具，字符串处理、信号槽、进程、文件系统，很多老 Linux C++ 项目依赖它。

- Linux Gnome&&Fedora 38
    Fedora 是 Linux 发行版，Gnome 是它默认桌面环境；现在新版 Fedora 默认后端是**Wayland**。


- kdenlive、shotcut
    Linux 下开源视频剪辑软件，本项目的对标参考软件，底层都基于 FFmpeg。

- Wayland核心协议
    Linux 新一代图形显示协议，替代老旧 X11；程序要截图、录屏、窗口渲染，都要和 Wayland 打交道，这是 Linux 桌面开发最大坑点。

- FFmpeg
    音视频处理万能库，解码、编码、滤镜、时间戳处理，视频剪辑核心底层。

- ONNXRuntime
    推理引擎，跑 ONNX 格式 AI 模型；项目做 AI 智能剪辑，目标检测、画面分割模型都靠它推理。
    
- DBus
    Linux 桌面进程间通信 (IPC) 总线。UI 程序、系统服务之间互相发消息、调用功能，靠 DBus。比如录屏权限申请就要用 DBus。
